# Sacha Bumann Portfolio

> Portfolio website for Sacha Bumann — Microengineering student at EPFL, founder of Yotta Technology SNC, aerospace enthusiast.

## Stack

- **Next.js 15** (App Router, React 19)
- **Tailwind CSS** with custom Kinetic Orange palette
- **Framer Motion** — scroll-reveal, parallax, spring animations
- **Lenis** — ultra-smooth scrolling
- **Lucide React** — 1.25px stroke icons
- **Geist Sans / Geist Mono** — precision typography

## Development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Sections

1. **Hero** — Full-screen mountain parallax, name, status bar
2. **Status** — EPFL + Yotta Technology system-log cards
3. **The Vault** — Hybrid Rocket Engine + FPV/PC grid
4. **The Frequency** — Music visualizer + track list
5. **Terminal** — Social links with orange flash, contact
